¿Cómo se usa?
1. Las 8 filas son instrumentos; las 8 columnas son corcheas de un compás 4/4. Haz clic en una celda para cambiar la intensidad.
2. Edita A y B, elige una operación y observa la matriz C. Los valores se normalizan entre 0 y 1 y se convierten a 0–3 para sonar.
3. Pulsa ▶ para escuchar A, B o C. Configura las intensidades en el mezclador: cada fuerza utiliza una grabación diferente, además de cambiar el volumen.
4. Para usar tus propios archivos, abre las opciones de un canal y carga hasta tres muestras (WAV, MP3, FLAC u otros formatos que soporte el navegador).
La inversa algebraica A⁻¹ solo existe cuando A es invertible. El programa lo indicará cuando sea singular.
